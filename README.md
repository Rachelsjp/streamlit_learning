# 🚀 Streamlit Learning Projects

## Description

This repository contains beginner-level Streamlit projects created to learn the fundamentals of building interactive web applications using Python and Streamlit.

The projects demonstrate user input handling, buttons, calculations, and dynamic UI interactions.

## Tech Stack

* Python 3.x
* Streamlit

---

## Projects

### 1. Streamlit Hello App

**File:** `streamlit_demo.py`

Features:

* Accepts user input
* Displays personalized greeting messages
* Demonstrates basic Streamlit components

---

### 2. Simple Calculator

**File:** `simple_calculator.py`

Features:

* Addition
* Subtraction
* Multiplication
* Division
* Input validation for division by zero

---

## Installation

Install Streamlit:

```bash
pip install streamlit
```

---

## Run Streamlit Hello App

```bash
streamlit run streamlit_demo.py
```

---

## Run Simple Calculator

```bash
streamlit run simple_calculator.py
```
